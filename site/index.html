        OpenRouter stays out of your totals, because OpenCode or Hermes may have counted the same spend already. Costs are estimates at API prices unless a tool reports its own, and a model with no known price shows a dash, never $0.

        Your usage stays on your Mac.

        This app reads sensitive folders and holds credentials, so here is exactly what it touches.

        What it reads

        • Usage figures from agent logs and databasesOpened read-only. Hermes and OpenCode are read from a temporary copy.
        • Your Claude login, from KeychainOnly to read your quota. Never stored, logged or refreshed.
        • Your Cursor cookie and OpenRouter keyOnly if you paste them. Kept in Buku Token's own Keychain items until you disconnect. Those items survive uninstalling, so disconnect first. The cookie is a full account session, so treat it like a password.
        • Project folder namesIt walks folder names from / and checks for .git, so macOS may ask for folder access.

        What it leaves alone

        • Project files
        • Your conversationsLogs are parsed for usage fields only.
        • Cursor's own database or Keychain
        • Antigravity conversations, titles or your Google token

        The only network calls

        • api.anthropic.comClaude quota
        • cursor.comOnce you connect it
        • openrouter.aiOnce you connect it
        • raw.githubusercontent.comPrice list, when you press Update

        Share the number, not the details.

        Turn a day, a week or a month into a card you can post. It's drawn on your Mac, with no upload and no link.

        • Choose all agents or just one.
        • Hide the cost, and the card shows token shares instead.
        • Project names, paths and emails never reach the image. Unknown model names show as “Other Model”.

        Light or dark, English or Indonesian.

        It follows your Mac's appearance, and you pick the language in Settings. It can notify you when a quota drops below 15%, and it tries to hide the menu bar figures while you share your screen.

        Install it with one command.

        You need Homebrew and an Apple Silicon Mac.

        View on GitHub

        A few limits: Cursor's endpoints are undocumented and can change, Codex quota is only as fresh as your last session, and Antigravity shows activity without tokens or cost. The README lists the rest.

        1. 1

          Install it

          brew install --cask fizipan/tap/buku-token
        2. 2

          Open it from Applications

          It stays in the menu bar, with no Dock icon. When macOS asks about Claude Code-credentials, choose Always Allow to see your Claude quota. Everything else works if you refuse.

        3. 3

          Update it the same way

          brew upgrade --cask buku-token

        The app isn't notarized by Apple. It's signed with a self-signed certificate, so the cask removes the download quarantine flag to let macOS open it. If you'd rather not allow that, build it from source.

        Other ways to install

        There's a DMG on the Releases page. macOS blocks its first open, so go to System Settings, then Privacy & Security, and choose Open Anyway.

        To build from source, which Intel Macs also need, you'll want Node.js, pnpm, Rust and the Xcode Command Line Tools.

        1. 1

          Create a signing certificate, once

          In Keychain Access, open Certificate Assistant and create a certificate named Buku Token Local, with Self-Signed Root and Code Signing. It lets macOS remember your Keychain answer after a rebuild.

        2. 2

          Build the app

          git clone https://github.com/fizipan/buku-token.git
cd buku-token
pnpm install
pnpm tauri build --bundles app
        3. 3

          Move it to Applications and open it

          You'll find it at src-tauri/target/release/bundle/macos/Buku Token.app. When macOS asks about Claude Code-credentials, choose Always Allow to see your Claude quota. Everything else works if you refuse.
